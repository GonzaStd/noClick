# Game Name

noClick: *Zero Clicks. Full access.*

# Developer

Gonzalo Vattino

# Short Game Description

This game aims to teach technical and realistic concepts in the most user-friendly way possible. The player will be a hacker who learns cybersecurity concepts and techniques progressively as they advance through the levels.

The player must analyze situations, make decisions, and apply real-world concepts within scenarios inspired by reality, featuring penetration testing and social engineering.

# How to Download and Run the Project
## Windows (x64)
### 1. Download the project

Choose one of the following two options:

#### 1.1 Download and install Git

1. Download the `Git-{version}-64-bit.exe` from the [latest release](https://github.com/git-for-windows/git/releases/latest) of the official git for windows repository (github.com/git-for-windows/git).
2. Double-click and follow the [installation steps](https://www.youtube.com/watch?v=4sw0ROVaoQ0) (it's intuitive, you don't necessarily need to watch the video).
3. In your preferred folder (Documents, Desktop), open a terminal (right-click and select "Open in Terminal" or press Win + R, type "cmd" and use `dir` and `cd` to navigate to the folder).
4. Once the terminal is in the destination folder, execute the following command: `git clone https://github.com/GonzaStd/noClick` and press enter to clone this repository into that folder.

#### 1.2 Download and extract the .zip

1. At the top of the repository page, there is a green dropdown button that says "Code". Click on it.
2. Click on the last option that says "Download ZIP".
3. Right-click on the downloaded `.zip` file and select "Extract to `\noClick`" or a similar option.

### 2. Download and install dependencies and run the project
#### 2.1 Download and install Java
Download the [Java 21 Development Kit](https://download.oracle.com/java/21/latest/jdk-21_windows-x64_bin.exe) and follow the [installation instructions](https://www.youtube.com/watch?v=i7JWf6Os8rI).

#### 2.2 Run the project using gradlew
Run a gradlew task in the terminal with the following command: `gradlew.bat lwjgl3:run`. This will compile and execute the project.
